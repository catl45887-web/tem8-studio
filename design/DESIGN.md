# mytemtime 首页设计规范（DESIGN.md）

适用：mytemtime.com 浅色 / 深色主题的所有页面，首页优先。圣诞主题只沿用"结构"规则，不沿用配色。
参考来源：用户提供的考研 App 首页截图（iPad，2026-11-05）+ 网站当前首页截图 + 用户此前定下的偏好。

## 1. Visual Theme & Atmosphere
- 一句话：**打开就能刷题的纸面工具**。上面一行倒计时，下面直接是入口，不需要先点底栏再找。
- 从参考图借的是"密度和顺序"：倒计时在顶、入口紧跟、每个入口一行字说明、整页一屏看完。
- 不借参考图的"彩色渐变大卡片"和图标——保持现在的米纸底色 + 宋体 + 一个酒红强调色。

## 2. Color（2026-11-05 定稿）
浅色、深色各四套配色，在「我的 → 外观」里先选浅色/深色，再选色块；没选中的那组收起。跟随系统时白天用选中的浅色、夜里用选中的深色。

| | 浅色 | 深色 |
|---|---|---|
| 默认 | 雾蓝 fog | 墨黑 ink |
| | 薄荷 mint | 石墨 graphite |
| | 奶霜 cream | 深蓝 navy |
| | 冬日 winter | 咖啡 coffee |

每套固定的角色（色值都在 `palettes.css` 的 `--p-*` 变量里）：

| 角色 | 用在哪 |
|---|---|
| bg 底色 | 整页背景，面积最大 |
| card 卡片 | 列表卡、面板（浅色一律白） |
| light 浅色 | 继续条、小标签 |
| main 主色 | 所有"选中"：年份、筛选胶囊、分段短横线 |
| dark 深色 | 箭头 ›、图标 |
| strong 强调 | 倒计时数字、主按钮 |
| ink / muted | 正文 / 次要文字 |

- 大面积的灰阶由 `tools/gen-themes.py` 生成到 `theme-light.css` / `theme-dark.css`，输出为 `hsl(var(--p-h) …)`，跟着配色的色相走；改原样式后重跑一次。
- 新加配色：在 `palettes.css` 写一组 `--p-*`，在 index.html 设置页加一个色块，在 themes.js 和 index.html 头部脚本的 PAL 表里加上浏览器顶栏颜色。
- 主色、深色不能当小字颜色（对比度不够）；答对/答错、护眼黄阅读背景保留原色。
- 年份按钮后面不加任何小圆点标记。

## 3. Typography
- 全站宋体 / 衬线（`serif.css` 已有）。
- 倒计时：数字 28–32px 酒红，"距离专八还有 / 天" 15px muted。比现在大一号——这是参考图里最值得借的一点：数字是页面的锚。
- 入口标题 17–18px，weight 500；说明 13px muted，一行，不超过 16 个汉字。
- 分组小标题（听力 / 阅读 …）13px muted，字距 2px。

## 4. Spacing & Grid
- 内容最大宽 720px 居中（iPad 横屏不拉满）；手机左右 16px。
- 节奏：倒计时块 → 24px → 继续卡 → 28px → 分组标题 → 8px → 入口组。
- 入口行高 ≥ 56px（手指好点）；组内行与行之间 0 间距，靠卡片内分隔。

## 5. Layout & Composition（首页从上到下，2026-11-05 定稿）
1. 倒计时行："距离专八还有 **128** 天"，数字 32px 酒红；紧跟一个日历小图标，点它改考试日期；本周学习天数放在同一行最右，13px muted。
2. 继续条：一行高 48px，像参考图的"定制计划表"横条——左"继续读/开始读"（酒红小字）+ 文章名，右侧段数和 `›`。
3. 四个分段：**精读 | 题型练习 | 模考 | 精听**。手机上四等分；≥600px 靠左排、间距 40px。
4. 分段下面就是原来的阅读列表 / 按题型列表 / 模考年份 / 精听年份，内容不变。
- 底栏：首页 / 复习 / 我的 三栏（浅色、深色）。圣诞主题保持五栏和雪景首页。

## 6. Components
- **分段按钮**：未选中 16px、weight 400、muted；选中 weight 600、`--ink`，下方 20×3px 圆头短横线（`--ink`）。分段下一条 1px `--line`。
- **继续条**：`--card` 底、圆角 12px、无边框无阴影；按下变 `--soft`。
- **日历图标**：19px 线框，1.6 描边，muted；热区 36×36。全站只有这一个功能图标（底栏仍然纯文字）。
- **列表卡**：沿用现有——`--card` 底、圆角 18px、无边框、无阴影、行间不画线、右端细 `›`。

## 7. Motion & Interaction
- 点行：背景变 `--soft`，120ms；不做位移、不做缩放。
- 点"听力 A"等直接进现有的练习配置页（`workflow-config`），配置页记住上次的年份，第二次点可以一键开始。
- 无入场动画（开屏水波纹已经有了，首页不再加）。

## 8. Voice & Brand
- 说明文字写"做什么"，不写口号：✅"Mini-lecture 填空" ❌"每天 10 分钟，搞定长难句"。
- 不用感叹号，不用"加油""冲"之类。
- 数字用阿拉伯数字。

## 9. Anti-patterns（看到就算不合格）
- 彩色渐变卡、每个入口不同颜色（参考图的做法，不要）。
- 入口前的 emoji / 图标 / 符号（包括现在练习页用的 ◖ ♫ ▧ ⌁ ↗︎ ✒）。
- 卡片阴影、卡片边框、行间分隔线。
- 首页出现搜索框、通知铃、"考研同桌"这类社交/营销位。
- 2×3 网格大方块——手机上字会挤，行列表更快。
- 酒红出现超过两处。
- "配置练习 ↗︎"这类重复的卡片脚注。
